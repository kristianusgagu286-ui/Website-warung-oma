# ⚡ Mulai Cepat - Warung Oma Website

## 🚀 3 Langkah Mulai Menggunakan

---

## Langkah 1: Buka Website

```
📁 Double-click file: index.html
```

Website akan terbuka di browser Anda!

---

## Langkah 2: Coba Pesan

1. Scroll ke bagian "Produk"
2. Klik tombol **"Pesan Sekarang"** di produk manapun
3. Isi form pemesanan:
   - Nama: [nama Anda]
   - Produk: [sudah terpilih]
   - Jumlah: [berapa porsi]
   - Alamat: [alamat lengkap]
4. Klik **"Kirim Pesanan"**
5. ✅ Pesanan berhasil!

---

## Langkah 3: Login ke Backend

1. Klik tombol **"🔐 Admin"** (pojok kanan atas atau footer)
2. Login dengan:
   ```
   Username: admin
   Password: admin123
   ```
3. Klik **"Login to Backend"**
4. 🎉 Selamat! Anda masuk ke backend!
