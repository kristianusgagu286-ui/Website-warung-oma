## 🚀 Cara Paling Mudah: NETLIFY

### Step 1: Siapkan File (1 menit)

```
1. Buat folder baru: "warung-oma-online"
2. Copy file ini ke folder:
   ✅ index.html
   ✅ style.css
   ✅ script.js
   ✅ backend.html
   ✅ backend-script.js
   ✅ admin-simple.html
3. Zip folder (klik kanan → Compress)
```

### Step 2: Daftar Netlify (2 menit)

```
1. Buka: https://www.netlify.com
2. Klik "Sign up"
3. Pilih "Sign up with Email" atau "GitHub"
4. Isi data & verifikasi email
```

### Step 3: Deploy (2 menit)

```
1. Login ke Netlify
2. Klik "Add new site" → "Deploy manually"
3. Drag & drop file ZIP ke area upload
4. Tunggu 30 detik
5. ✅ SELESAI!
```

### Step 4: Dapatkan Link

```
Netlify akan memberikan link seperti:
https://random-name-12345.netlify.app

Ganti nama (optional):
1. Klik "Site settings"
2. Klik "Change site name"
3. Ketik: warung-oma
4. Link jadi: https://warung-oma.netlify.app
```
