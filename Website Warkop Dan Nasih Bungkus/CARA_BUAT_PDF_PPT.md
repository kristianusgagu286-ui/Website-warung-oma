## CARA 1: Buat PowerPoint Manual (RECOMMENDED)

### Step 1: Buka PowerPoint
```
1. Buka Microsoft PowerPoint
2. Klik "Blank Presentation" atau pilih template
```

### Step 2: Copy Template
```
1. Buka file: TEMPLATE_POWERPOINT.md
2. Copy konten setiap slide
3. Paste ke PowerPoint
4. Sesuaikan format
```

### Step 3: Tambah Visual
```
1. Screenshot website (index.html)
2. Screenshot backend (backend.html)
3. Foto produk
4. Diagram alur
```

### Step 4: Design
```
1. Pilih theme/template
2. Konsisten warna
3. Font readable
4. Animasi sederhana
```

### Step 5: Save as PDF
```
1. File → Save As
2. Format: PDF
3. Klik Save
```

**Waktu:** 30-60 menit  
**Hasil:** PowerPoint + PDF  
**Kualitas:** ⭐⭐⭐⭐⭐

## 📊 Cara Membuat PowerPoint Profesional

### 1. Pilih Template

**Sumber Template Gratis:**
- PowerPoint built-in templates
- https://www.slidesgo.com
- https://www.canva.com/templates/presentations/
- https://www.slidescarnival.com

**Tips Memilih:**
- Pilih yang profesional
- Sesuai tema (teknologi/bisnis)
- Tidak terlalu ramai
- Konsisten warna

### 2. Struktur Slide

**Slide Wajib:**
1. Cover (Judul proyek)
2. Identitas kelompok
3. Latar belakang
4. Tujuan
5. Teknologi
6. Fitur website
7. Demo/Screenshot
8. Backend system
9. Testing
10. Kesimpulan
11. Q&A

**Slide Optional:**
- Profil UMKM
- Produk detail
- Kendala & solusi
- Pembelajaran
- Saran pengembangan

### 3. Design Guidelines

**Warna:**
```
Primary: #e74c3c (Merah)
Secondary: #27ae60 (Hijau)
Accent: #3498db (Biru)
Background: White atau Light Gray
Text: Dark Gray atau Black
```

**Font:**
```
Heading: Arial Bold, 32-44pt
Subheading: Arial, 24-28pt
Body: Arial, 18-20pt
Caption: Arial, 14-16pt
```

**Layout:**
```
Margin: 1 inch semua sisi
Bullet points: Maksimal 5-6 per slide
Images: High quality, aligned
Spacing: Konsisten
```

### 4. Screenshot yang Diperlukan

**Website:**
1. Hero section (full page)
2. Products section (grid produk)
3. Order form (kosong & terisi)
4. Success message
5. Mobile view

**Backend:**
1. Login page
2. Dashboard (dengan data)
3. Orders management (tabel)
4. Products management (tabel)
5. Add product modal
6. Edit product modal

**Cara Screenshot:**
```
Windows: Win + Shift + S
Mac: Cmd + Shift + 4
Chrome: F12 → Device toolbar → Screenshot
```

### 5. Animasi

**Entrance (Masuk):**
- Fade in
- Fly in from bottom
- Wipe

**Emphasis (Penekanan):**
- Grow/Shrink
- Bold flash
- Color pulse

**Exit (Keluar):**
- Fade out
- Fly out

**Tips:**
- Jangan berlebihan
- Konsisten di semua slide
- Timing: 0.5-1 detik

### 6. Transisi Slide

**Recommended:**
- Fade
- Push
- Wipe
- None (paling aman)

**Timing:** 0.5-1 detik

## 📄 Cara Convert ke PDF

### Dari PowerPoint

#### Windows:
```
1. Buka PowerPoint
2. File → Save As
3. Browse lokasi
4. Save as type: PDF (*.pdf)
5. Options:
   ✓ Optimize for: Standard
   ✓ Publish what: All slides
6. Klik Save
```

#### Mac:
```
1. Buka PowerPoint
2. File → Export
3. File Format: PDF
4. Quality: Best for printing
5. Klik Export
```

### Dari Google Slides

```
1. Buka presentasi di Google Slides
2. File → Download
3. Pilih "PDF Document (.pdf)"
4. File akan otomatis download
```

### Online Converter

**A. SmallPDF**
```
1. Buka: https://smallpdf.com/ppt-to-pdf
2. Upload file PowerPoint
3. Tunggu convert
4. Download PDF
```

**B. ILovePDF**
```
1. Buka: https://www.ilovepdf.com/powerpoint_to_pdf
2. Select PowerPoint file
3. Convert to PDF
4. Download
```

**C. Zamzar**
```
1. Buka: https://www.zamzar.com/convert/ppt-to-pdf/
2. Upload PPT
3. Convert
4. Download PDF
```

## 🆘 Troubleshooting

### PowerPoint Tidak Bisa Dibuka
**Solusi:**
- Install Microsoft Office
- Atau gunakan Google Slides
- Atau gunakan LibreOffice Impress (gratis)

### Gambar Tidak Muncul di PDF
**Solusi:**
- Embed images di PowerPoint
- Compress images
- Save as PDF dengan quality "High"

### File PDF Terlalu Besar
**Solusi:**
- Compress images sebelum insert
- Gunakan online PDF compressor
- https://www.ilovepdf.com/compress_pdf

### Font Berubah di PDF
**Solusi:**
- Embed fonts di PowerPoint
- File → Options → Save → Embed fonts
- Atau gunakan standard fonts (Arial, Calibri)
