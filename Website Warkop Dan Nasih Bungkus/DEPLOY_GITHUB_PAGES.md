## 📖 Panduan Lengkap Deploy di GitHub

---

Setelah deploy, website Anda akan online di:
```
https://username.github.io/warung-oma
```
Ganti "username" dengan username GitHub Anda.

---

## 📋 Step-by-Step Deploy

### Step 1: Buat Akun GitHub (5 menit)

#### 1.1 Buka GitHub
```
Buka browser, ketik: https://github.com
```

#### 1.2 Sign Up
```
1. Klik tombol "Sign up" (pojok kanan atas)
2. Isi form:
   - Email: [email Anda]
   - Password: [buat password kuat]
   - Username: [pilih username unik]
   
   Contoh username: budisantoso, warungoma, dll
   
3. Klik "Continue"
4. Verifikasi (puzzle/captcha)
5. Klik "Create account"
```

#### 1.3 Verifikasi Email
```
1. Cek email Anda
2. Buka email dari GitHub
3. Klik link verifikasi
4. ✅ Akun GitHub aktif!
```

---

### Step 2: Buat Repository (2 menit)

#### 2.1 Login ke GitHub
```
1. Buka: https://github.com
2. Login dengan email & password
```

#### 2.2 Buat Repository Baru
```
1. Klik tombol "+" (pojok kanan atas)
2. Pilih "New repository"
```

#### 2.3 Isi Detail Repository
```
Repository name: warung-oma
Description: Website UMKM Warung Oma (optional)

Pilihan:
✅ Public (harus public untuk GitHub Pages gratis)
❌ Jangan centang "Add a README file"
❌ Jangan pilih .gitignore
❌ Jangan pilih license

Klik "Create repository"
```

---

### Step 3: Upload File Website (3 menit)

#### 3.1 Di Halaman Repository Baru
```
Anda akan lihat halaman kosong dengan instruksi.
Cari tulisan: "uploading an existing file"
Klik link tersebut.
```

#### 3.2 Upload File
```
1. Klik "choose your files" atau drag & drop

2. Pilih file-file ini dari komputer Anda:
   ✅ index.html
   ✅ style.css
   ✅ script.js
   ✅ backend.html
   ✅ backend-script.js
   ✅ admin-simple.html
   
   (Bisa pilih semua sekaligus dengan Ctrl+Click)

3. Tunggu upload selesai (progress bar hijau)
```

#### 3.3 Commit Changes
```
Di bawah, ada form "Commit changes":

Commit message: Upload website files
(Biarkan default atau tulis pesan Anda)

Klik tombol hijau "Commit changes"
```

#### 3.4 Tunggu Upload Selesai
```
✅ File akan muncul di repository
✅ Anda akan lihat list file
```

---

### Step 4: Aktifkan GitHub Pages (2 menit)

#### 4.1 Buka Settings
```
1. Di halaman repository, klik tab "Settings"
   (Tab paling kanan, ada icon gear ⚙️)
```

#### 4.2 Cari Menu Pages
```
1. Di sidebar kiri, scroll ke bawah
2. Cari dan klik "Pages"
```

#### 4.3 Aktifkan GitHub Pages
```
Di bagian "Source":

1. Branch: Pilih "main" (atau "master")
2. Folder: Pilih "/ (root)"
3. Klik tombol "Save"
```

#### 4.4 Tunggu Deploy
```
Akan muncul notifikasi biru:
"Your site is ready to be published at https://username.github.io/warung-oma"

Tunggu 1-2 menit untuk proses deploy.
```

---

### Step 5: Akses Website Online! 🎉

#### 5.1 Dapatkan Link
```
Setelah 1-2 menit, refresh halaman Settings → Pages

Akan muncul notifikasi hijau:
"Your site is published at https://username.github.io/warung-oma"
```

#### 5.2 Buka Website
```
Klik link tersebut atau copy-paste ke browser baru.

✅ Website Anda sudah online!
```

## 🔄 Cara Update Website

### Jika Ada Perubahan File:

#### Cara 1: Upload via Web (Mudah)

```
1. Login ke GitHub
2. Buka repository: warung-oma
3. Klik file yang mau diupdate (misal: index.html)
4. Klik icon pensil (Edit) di pojok kanan
5. Edit file
6. Scroll ke bawah, klik "Commit changes"
7. Tunggu 1-2 menit
8. ✅ Website updated!
```

#### Cara 2: Upload File Baru

```
1. Login ke GitHub
2. Buka repository: warung-oma
3. Klik "Add file" → "Upload files"
4. Drag & drop file baru
5. Klik "Commit changes"
6. Tunggu 1-2 menit
7. ✅ Website updated!
```

## 🎨 Custom Domain (Optional)

### Jika Punya Domain Sendiri:

#### Step 1: Beli Domain
```
Beli di:
- Namecheap.com
- GoDaddy.com
- Niagahoster.co.id

Harga: ~Rp 100.000 - 200.000/tahun
```

#### Step 2: Setting di GitHub
```
1. Buka Settings → Pages
2. Di "Custom domain", ketik domain Anda
   Contoh: warungoma.com
3. Klik "Save"
```

#### Step 3: Setting DNS
```
Di registrar domain (Namecheap/GoDaddy):

1. Buka DNS settings
2. Tambah record:
   Type: CNAME
   Name: www
   Value: username.github.io
   
3. Save
4. Tunggu 24 jam
5. ✅ Domain aktif!
```

**Hasil:**
```
Dari: https://username.github.io/warung-oma
Jadi: https://warungoma.com
```

## ⚠️ Troubleshooting

### 1. Website Tidak Muncul (404 Error)

**Solusi:**
```
✅ Tunggu 2-5 menit setelah deploy
✅ Pastikan file index.html ada di root folder
✅ Pastikan repository Public (bukan Private)
✅ Pastikan GitHub Pages sudah diaktifkan
✅ Refresh browser (Ctrl+F5)
✅ Clear cache browser
```

### 2. CSS/JS Tidak Load

**Solusi:**
```
✅ Cek path file di HTML
✅ Pastikan file style.css dan script.js sudah diupload
✅ Cek nama file (case-sensitive)
✅ Hard refresh (Ctrl+Shift+R)
```

### 3. Gambar Tidak Muncul

**Solusi:**
```
✅ Gambar dari Unsplash butuh internet
✅ Cek URL gambar valid
✅ Tunggu loading
✅ Coba browser lain
```

### 4. Repository Private

**Solusi:**
```
GitHub Pages gratis hanya untuk repository Public.

Cara ubah ke Public:
1. Settings → General
2. Scroll ke bawah
3. Cari "Danger Zone"
4. Klik "Change visibility"
5. Pilih "Make public"
6. Konfirmasi
```

## 📊 Perbandingan: Netlify vs GitHub Pages

```
┌─────────────────┬──────────────┬──────────────────┐
│    Fitur        │   Netlify    │  GitHub Pages    │
├─────────────────┼──────────────┼──────────────────┤
│ Kemudahan       │ ⭐⭐⭐⭐⭐    │ ⭐⭐⭐⭐         │
│ Deploy          │ Drag & drop  │ Upload manual    │
│ Link            │ .netlify.app │ .github.io       │
│ Custom domain   │ ✅ Mudah     │ ✅ Bisa          │
│ HTTPS           │ ✅ Otomatis  │ ✅ Otomatis      │
│ Bandwidth       │ 100GB/bulan  │ 100GB/bulan      │
│ Build time      │ Cepat        │ 1-2 menit        │
│ Update          │ Instant      │ 1-2 menit        │
└─────────────────┴──────────────┴──────────────────┘
```

**Rekomendasi:**
- **Netlify** - Lebih mudah, drag & drop
- **GitHub Pages** - Bagus untuk portfolio, gratis, reliable
