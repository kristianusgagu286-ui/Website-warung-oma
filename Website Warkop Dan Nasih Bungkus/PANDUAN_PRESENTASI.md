## 🎯 Tips Presentasi

1. **Pembagian Waktu:**
   - Jangan terlalu lama di satu bagian
   - Sisakan waktu untuk demo dan tanya jawab
   - Gunakan timer untuk monitoring

2. **Demo:**
   - Pastikan semua fitur sudah di-test sebelumnya
   - Siapkan data dummy yang menarik
   - Jangan demo fitur yang masih error

3. **Komunikasi:**
   - Gunakan bahasa yang mudah dipahami
   - Hindari istilah teknis yang terlalu rumit
   - Jelaskan dengan analogi jika perlu

4. **Visual:**
   - Slide tidak terlalu banyak teks
   - Gunakan gambar/screenshot
   - Font size minimal 24pt

5. **Backup Plan:**
   - Siapkan video recording demo jika live demo gagal
   - Print screenshot penting
   - Simpan file di USB dan cloud

---

## 📱 Kontak Darurat

Jika ada masalah teknis saat presentasi:
1. Restart browser
2. Buka file dari folder backup
3. Gunakan browser alternatif (Chrome/Firefox/Edge)
4. Clear localStorage jika data corrupt
5. Gunakan video backup
