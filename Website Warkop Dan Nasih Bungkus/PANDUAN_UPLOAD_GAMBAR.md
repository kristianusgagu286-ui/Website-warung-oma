# 📸 Panduan Upload Gambar Produk

## 🎯 Fitur Baru: Upload Gambar Produk

Sekarang Anda bisa menambahkan produk baru dengan mudah menggunakan fitur upload gambar!

## 🚀 Cara Menambah Produk Baru dengan Upload Gambar

### Langkah 1: Login ke Admin Panel
1. Buka file `admin.html` di browser
2. Login dengan:
   - Username: `admin`
   - Password: `admin123`

### Langkah 2: Buka Menu Produk
1. Klik menu **"Produk"** di navigation bar
2. Anda akan melihat daftar produk yang sudah ada

### Langkah 3: Tambah Produk Baru
1. Klik tombol **"Tambah Produk"** (warna merah)
2. Form tambah produk akan muncul

### Langkah 4: Isi Data Produk
Isi semua field yang diperlukan:

**1. Nama Produk** (Wajib)
   - Contoh: "Nasi Campur Spesial"
   - Minimal 2 karakter

**2. Harga** (Wajib)
   - Contoh: 25000
   - Hanya angka, tanpa "Rp" atau titik

**3. Deskripsi**
   - Contoh: "Nasi campur dengan lauk lengkap dan sambal pedas"
   - Jelaskan produk dengan menarik

**4. Kategori**
   - Pilih: Makanan, Minuman, atau Snack

**5. Gambar Produk** (Pilih salah satu):

   **Opsi A: Upload Gambar dari Komputer** ⭐ BARU!
   - Klik tombol **"Choose File"** atau **"Pilih File"**
   - Pilih gambar dari komputer Anda
   - Format yang didukung: JPG, PNG, GIF
   - Ukuran maksimal: 2MB
   - Preview gambar akan muncul otomatis

   **Opsi B: Gunakan URL Gambar**
   - Masukkan link gambar dari internet
   - Contoh: `https://example.com/gambar-produk.jpg`

**6. Status Tersedia**
   - Centang jika produk tersedia
   - Uncheck jika stok habis

### Langkah 5: Simpan Produk
1. Klik tombol **"Simpan"**
2. Produk baru akan muncul di daftar
3. Produk otomatis muncul di halaman utama website
4. Produk otomatis masuk ke dropdown form pemesanan

## ✏️ Cara Edit Produk yang Sudah Ada

### Langkah 4: Lihat Hasil
1. Produk akan terupdate di daftar
2. Perubahan langsung terlihat di website utama

## 📸 Tips Memilih Gambar Produk yang Baik

### 1. Kualitas Gambar
- ✅ Gunakan gambar yang jelas dan tajam
- ✅ Resolusi minimal 300x200 pixel
- ✅ Maksimal 2MB agar loading cepat
- ❌ Hindari gambar blur atau pecah

### 2. Komposisi
- ✅ Fokus pada produk
- ✅ Background bersih dan tidak ramai
- ✅ Pencahayaan yang baik
- ❌ Hindari gambar terlalu gelap

### 3. Format File
- ✅ JPG/JPEG (paling umum)
- ✅ PNG (untuk gambar dengan transparansi)
- ✅ GIF (untuk gambar animasi)
- ❌ Hindari format lain (BMP, TIFF, dll)

### 4. Ukuran File
- ✅ Optimal: 100KB - 500KB
- ✅ Maksimal: 2MB
- ❌ Terlalu besar akan lambat loading

### 5. Orientasi
- ✅ Landscape (horizontal) lebih baik
- ✅ Rasio 3:2 atau 4:3 ideal
- ⚠️ Portrait (vertikal) akan di-crop otomatis

## 🔧 Cara Kompres Gambar (Jika Terlalu Besar)

1. **TinyPNG** - https://tinypng.com/
   - Upload gambar
   - Download hasil kompres
   - Kualitas tetap bagus

2. **Compressor.io** - https://compressor.io/
   - Drag & drop gambar
   - Pilih tingkat kompresi
   - Download hasil

3. **iLoveIMG** - https://www.iloveimg.com/compress-image
   - Upload multiple images
   - Kompres otomatis
   - Download semua

### Aplikasi Desktop:
1. **Paint** (Windows)
   - Buka gambar
   - Save As → pilih JPG
   - Atur quality slider

2. **GIMP** (Free, Windows/Mac/Linux)
   - Export → JPG
   - Atur quality 80-90%

## 📱 Cara Ambil Gambar dari HP

### Metode 1: Transfer via USB
1. Hubungkan HP ke laptop dengan kabel USB
2. Buka folder DCIM/Camera di HP
3. Copy gambar ke laptop

### Metode 2: Transfer via WhatsApp
1. Kirim gambar ke diri sendiri di WhatsApp
2. Buka WhatsApp Web di laptop
3. Download gambar
4. Upload di admin panel

### Metode 3: Transfer via Google Drive
1. Upload gambar ke Google Drive dari HP
2. Buka Google Drive di laptop
3. Download gambar
4. Upload di admin panel

### Metode 4: Transfer via Email
1. Email gambar ke diri sendiri
2. Buka email di laptop
3. Download attachment
4. Upload di admin panel

   - Download atau copy URL

3. **Pixabay** - https://pixabay.com/
   - 2.7 juta+ gambar gratis

   - Copy image URL

### Cara Copy URL Gambar:
1. Buka website gambar
2. Klik kanan pada gambar
3. Pilih **"Copy image address"** atau **"Salin alamat gambar"**
4. Paste di field "URL Gambar" di admin panel

## ⚠️ Troubleshooting

### Problem: File Terlalu Besar
**Error:** "Ukuran file terlalu besar! Maksimal 2MB"

**Solusi:**
1. Kompres gambar menggunakan tools di atas
2. Atau gunakan gambar dengan resolusi lebih kecil
3. Atau gunakan URL gambar dari internet

### Problem: Format File Tidak Didukung
**Error:** "File harus berupa gambar!"

**Solusi:**
1. Pastikan file berformat JPG, PNG, atau GIF
2. Convert file ke format yang didukung
3. Gunakan tools online untuk convert

### Problem: Gambar Tidak Muncul
**Solusi:**
1. Refresh halaman (F5)
2. Clear cache browser (Ctrl + Shift + Delete)
3. Coba upload ulang gambar
4. Pastikan gambar tidak corrupt

### Problem: Preview Tidak Muncul
**Solusi:**
1. Pastikan file adalah gambar valid
2. Coba pilih file lagi
3. Refresh halaman dan coba lagi

### Problem: Gambar Terpotong
**Solusi:**
1. Gunakan gambar dengan rasio 3:2 atau 4:3
2. Atau edit gambar dulu sebelum upload
3. Crop gambar agar fokus pada produk

## 💾 Penyimpanan Data

### Dimana Gambar Disimpan?
- Gambar yang di-upload disimpan di **localStorage browser**
- Gambar dikonversi ke format Base64
- Data tidak hilang meskipun browser ditutup
- Data tersimpan di komputer lokal

### Batasan localStorage:
- Kapasitas: ~5-10MB per domain
- Cukup untuk 20-50 produk dengan gambar
- Jika penuh, hapus produk lama yang tidak terpakai

### Backup Data:
Untuk production/website real:
1. Gunakan server backend (PHP, Node.js)
2. Simpan gambar di folder server
3. Gunakan database (MySQL, PostgreSQL)
4. Atau gunakan cloud storage (AWS S3, Cloudinary)
