# 🔐 Cara Akses Admin Panel

## 🎯 3 Cara Mudah Akses Admin

### **Cara 1: Dari Website Utama (PALING MUDAH!)**

1. **Buka `index.html`** (website utama)
2. Lihat di **menu navigasi** (pojok kanan atas)
3. Klik tombol **"🔐 Admin"** (warna merah)
4. Atau scroll ke bawah, klik **"🔐 Login Admin"** di footer
5. Anda akan dibawa ke halaman login
6. Login dengan:
   - **Username:** `admin`
   - **Password:** `admin123`
7. Selesai! ✅

---

### **Cara 2: Langsung Buka admin.html**

1. **Double-click** file `admin.html`
2. Form login akan muncul
3. Login dengan:
   - **Username:** `admin`
   - **Password:** `admin123`
4. Selesai! ✅

---

### **Cara 3: Gunakan test-login.html**

1. **Double-click** file `test-login.html`
2. Username & password sudah terisi otomatis
3. Klik tombol **"Login"**
4. Otomatis masuk ke admin panel
5. Selesai! ✅

---

## 🔄 Navigasi Antar Halaman

### Dari Website → Admin:
- Klik **"🔐 Admin"** di menu navigasi
- Atau klik **"🔐 Login Admin"** di footer

### Dari Admin → Website:
- Klik **"🏠 Website"** di header admin panel
- Atau buka `index.html` di tab baru

## 🎯 Untuk Presentasi

Saat presentasi, tunjukkan:

1. **Buka website utama** (`index.html`)
2. **Tunjukkan tombol Admin** di menu
3. **Klik tombol Admin**
4. **Login** dengan username & password
5. **Tunjukkan dashboard** dan fitur-fitur
6. **Klik tombol Website** untuk kembali
7. **Selesai!** Audience akan terkesan! 🎉
